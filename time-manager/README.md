# 刻ノ帳(時間管理アプリ)

ブラウザだけで動く、単独の時間管理アプリです。ゲーム本体(Godot プロジェクト)とは独立しており、
このフォルダには `.gdignore` を置いて Godot に取り込まれないようにしてあります。

## 使い方

`index.html` をブラウザで開くだけです。サーバーもビルドも要りません。
データはブラウザの `localStorage` に保存され、閉じても残ります。

## できること

- **タスク** — やることと見積もり回数を登録。クリックで「集中の対象」に選び、チェックで完了。
  各タスクに、実際に集中した回数と累計時間が表示されます。
- **集中タイマー** — 集中/小休憩/長休憩を自動で切り替えるポモドーロ式。
  一時停止・再開、「区切る」(集中を途中で終えても1分以上なら記録)、「戻す」。
  Space キーで開始/一時停止。タブを閉じても終了時刻を覚えており、開き直すと続きから動きます。
- **記録** — 今日の集中時間・回数・完了タスク数、直近7日の集中時間グラフ(表表示あり)、今日の履歴。
- **設定** — 各時間の長さ、長休憩の間隔、自動開始、終了音、デスクトップ通知。
- **データ** — JSON で書き出し/読み込み、全消去。
