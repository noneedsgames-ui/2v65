# 刻ノ帳(時間管理アプリ)

ブラウザだけで動く、単独の時間管理アプリです。ゲーム本体(Godot プロジェクト)とは独立しており、
このフォルダには `.gdignore` を置いて Godot に取り込まれないようにしてあります。

## 使い方

`index.html` をブラウザで開くだけです。サーバーもビルドも要りません。
データはブラウザの `localStorage` に保存され、閉じても残ります。

## できること

- **タスク** — やることと見積もり回数を登録。クリックで「集中の対象」に選び、チェックで完了。
  各タスクに、実際に集中した回数と累計時間が表示されます。
- **集中タイマー** — 集中/小休憩/長休憩を自動で切り替えるポモドーロ式。
  一時停止・再開、「区切る」(集中を途中で終えても1分以上なら記録)、「戻す」。
  Space キーで開始/一時停止。タブを閉じても終了時刻を覚えており、開き直すと続きから動きます。
- **メモ帳** — 箇条書きのメモを、タブごとに分けて書けます(「+」で追加、ダブルクリックで改名)。
  Enter で次の行、Tab / Shift+Tab で字下げ、Alt+↑↓ で行の入れ替え。空の行で Enter を押すと一段浅くなり、
  行頭で Backspace を押すと前の行とつながります。複数行の貼り付けは行ごとの箇条書きになり、
  「テキストでコピー」で `- ` 形式のテキストとして持ち出せます。
- **メモ帳の使用時間** — メモ帳を操作している間を、タブごとに自動で記録します。
  ほかの欄やほかのウィンドウへ移る、タブを隠す、3分間操作がない、のいずれかで止まります
  (操作がなかった3分は数えません)。1分以内に同じタブへ戻れば一続きの記録になり、5秒未満は残しません。
  設定で記録を切ることもできます。
- **記録** — 今日の集中時間・回数・完了タスク数・メモ帳の使用時間、直近7日の集中時間グラフ
  (表表示ではメモ帳の時間も並びます)、集中とメモ帳をまとめた今日の履歴。
- **設定** — 各時間の長さ、長休憩の間隔、自動開始、終了音、デスクトップ通知。
- **データ** — JSON で書き出し/読み込み、全消去。
