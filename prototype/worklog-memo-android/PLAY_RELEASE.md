# 作業記録メモ帳を Google Play の内部テストで配る

APK を直接入れると、ダウンロード時とインストール時に警告が出る。これはアプリの作りでは消せず、Google Play から入れれば出なくなる。ここでは、自分(と招いた人)だけが Play ストアから入れられる「内部テスト」で配る手順をまとめる。

ウイルス対策アプリ(ノートンなど)は、直接入れた試作版を「疑わしいアプリ」と出すことがある。提供元の分からない APK で、使用状況の読み取りや重ね表示といった強い権限を持つためと思われる。Play の版でも出るかどうかは、内部テストで確かめる。

## 全体の流れ

1. GitHub の Secrets にアップロード鍵を入れる(最初に一度だけ)
2. GitHub Actions を動かし、Play に出す AAB を作る
3. Google Play Console に開発者登録する(最初に一度だけ・25 ドル)
4. Play Console でアプリを作り、内部テストに AAB を上げる
5. スマホでテスター用のリンクを開き、Play ストアから入れる

## 1. GitHub の Secrets にアップロード鍵を入れる

アップロード鍵は Claude が作り、`UPLOAD_KEYSTORE_BASE64.txt`・`UPLOAD_KEYSTORE_PASSWORD.txt`・`upload.jks` の 3 つのファイルで渡している。リポジトリには入れていない。

1. GitHub でリポジトリを開き、**Settings › Secrets and variables › Actions** を開く
2. **New repository secret** で、次の 2 つを作る

| Name | Secret に貼るもの |
|---|---|
| `UPLOAD_KEYSTORE_BASE64` | `UPLOAD_KEYSTORE_BASE64.txt` の中身すべて |
| `UPLOAD_KEYSTORE_PASSWORD` | `UPLOAD_KEYSTORE_PASSWORD.txt` の中身 |

3. 3 つのファイルは、パソコンやクラウドの安全な場所にも保管しておく。なくすと Play に更新を出せなくなる(Play Console のサポートで鍵を作り直す手続きはできる)

## 2. AAB を作る

1. GitHub の **Actions › 作業記録メモ帳 APK › Run workflow** で動かす(手で動かしたときだけ動く)
2. 終わったら、その実行結果の画面の **Artifacts** から落とす。中の `worklog-memo-<番号>-play.aab` が Play に上げるファイル
   - `-play.aab` が無いときは、Secrets の名前や中身が違っている
   - Releases への公開は、Actions に書き込みの権限がないと失敗するが、Artifacts には残るので差し支えない
   - 版の番号は Actions の実行番号から決まる。手元の Android Studio で作った AAB は番号が合わないので、Play には上げない

## 3. Google Play Console に開発者登録する

1. https://play.google.com/console/signup を開き、「個人」で登録する
2. 登録料 25 ドルを払い、本人確認(身分証)を済ませる。確認には数日かかることがある

## 4. アプリを作り、内部テストに上げる

1. **アプリを作成**:アプリ名「作業記録メモ帳」、既定の言語「日本語」、「アプリ」「無料」
2. **テストとリリース › テスト › 内部テスト** を開く
3. **テスター** タブでメーリングリストを作り、自分の Google アカウント(スマホの Play ストアで使っているもの)を入れる
4. **新しいリリースを作成**
   - 「Play アプリ署名」は、Google に任せる(既定のまま)
   - App Bundle に `worklog-memo-<番号>-play.aab` を上げる
   - リリース名は自動のままでよい。「次へ」「保存して公開」
5. 下の「アプリのコンテンツ」で求められた項目があれば埋める
6. **テスター** タブの「テスターにリンクをコピー」で出るリンクを、スマホで開く

## 5. スマホで入れる

1. テスター用リンクを開き、「テスターになる」を押す
2. 表示される Play ストアのリンクから「インストール」
3. **直接入れた版について**
   - 試作 2 までの直接入れた版は、Play の版と同じアプリ名(パッケージ名)で署名が違うため、そのままでは Play の版を入れられない。先にアンインストールする。その版のメモや記録は消える
   - 試作 3 以降の直接入れた版は「作業記録メモ帳(試作)」という別のアプリになったので、Play の版と並べて置ける(データは別々)

## 更新するとき

Run workflow で新しい AAB ができる。内部テストで「新しいリリースを作成」して上げれば、スマホの Play ストアから更新できる。版の番号は自動で増える。

## アプリのコンテンツ(求められたときの回答と文案)

内部テストでは求められない項目もある。求められたら、次を使う。

### 広告
広告は含まない。

### アプリのアクセス権
すべての機能に制限なくアクセスできる(ログインなし)。

### ターゲット ユーザー
18 歳以上。

### データ セーフティ
- データの収集:**なし**
- データの共有:**なし**
- 理由:メモ・作業時間・予定・ほかのアプリの使用時間は、すべて端末の中で読み書きするだけで、端末の外へは送らない。アプリはネットワークに接続しない。

### 前景サービス(特殊用途)の申告
- 種類:特殊用途(specialUse)
- 説明文:

> 利用者が集中タイマーを始めたとき(アプリの画面、または通知のボタンから)だけ、最大 5 分間、前景サービスを動かします。そのあいだ、利用者が自分で選んだ「集中の妨げになるアプリ」が前面に出たら、このアプリの画面で上を覆い、集中を続けられるようにします。タイマーを止めるか 5 分が過ぎると、サービスは自動で止まります。通知から利用者がいつでも止められます。ほかの前景サービスの種類(メディア再生・位置情報など)には当てはまらないため、特殊用途を使います。

- 動画:タイマーを始め、選んだアプリを開くと覆われ、通知から止める様子をスマホの画面録画で撮り、YouTube(限定公開)などのリンクを入れる

### 使用状況へのアクセス(PACKAGE_USAGE_STATS)を使う理由

> 利用者が選んだアプリ(作業に使うアプリと、集中の妨げになるアプリ)の、1 日の使用時間を表示するために使います。また、集中タイマー中に、選んだ妨げになるアプリが前面に出たかを判断するために使います。読んだ情報は端末の外へ送りません。許可は利用者が端末の設定画面で自分で付け、いつでも外せます。

### 他のアプリの上に重ねて表示(SYSTEM_ALERT_WINDOW)を使う理由

> 集中タイマー中(最大 5 分)に、利用者が自分で選んだ集中の妨げになるアプリが前面に出たときだけ、その上を覆う画面を出すために使います。覆う画面からは、このアプリに戻るか、ホーム画面へ移れます。

### 通知と再起動の知らせ(POST_NOTIFICATIONS・RECEIVE_BOOT_COMPLETED)を使う理由

> ロック画面にも出る通知で、ストップウォッチを始める・止めるボタンと経過時間を見せ、予定の時刻、ポモドーロの区切り、タイマーの止め忘れを知らせるために使います。端末を再起動すると通知と知らせの予約が消えるので、再起動の知らせを受けて預け直します。ロック画面の通知は設定でいつでも切れます。

### 正確なアラーム(SCHEDULE_EXACT_ALARM)を使う理由

> 利用者が登録した予定の時刻と、ポモドーロの区切りを、遅れずに知らせるために使います。許可は利用者が端末の「アラームとリマインダー」で自分で付けます。許可がなくても知らせは届き、数分遅れることがあるだけです。

(`USE_EXACT_ALARM` は使わない。こちらはカレンダーや目覚ましのアプリ向けで、Play の審査が厳しい)

## プライバシーポリシー(文案)

Play Console に URL を入れるために、次の文を Web ページとして公開する(Claude Artifact、GitHub Pages など)。

> **作業記録メモ帳 プライバシーポリシー**
>
> 作業記録メモ帳(以下「本アプリ」)は、利用者の作業時間の記録とメモのためのアプリです。
>
> **1. 扱う情報**
> - 利用者が書いたメモ、ボードの配置、予定、タイマーの記録
> - 本アプリを開いていた時間
> - 利用者が選んだアプリの使用時間(端末の「使用状況へのアクセス」を利用者が許可した場合のみ)
> - 端末に入っているアプリの名前の一覧(利用者がアプリを選ぶときのみ)
>
> **2. 情報の保存と送信**
> 上の情報は、すべて利用者の端末の中にだけ保存します。本アプリは、これらの情報を開発者やほかの第三者に送信しません。本アプリはネットワークに接続せず、端末のクラウドバックアップの対象にもしません。利用者が自分で書き出したファイルの扱いは、利用者に委ねられます。
>
> **3. 権限**
> - 使用状況へのアクセス:選んだアプリの使用時間を表示し、集中タイマー中に選んだアプリが前面に出たかを判断するために使います。
> - 他のアプリの上に重ねて表示:集中タイマー中(最大 5 分)に、選んだアプリの上を覆う画面を出すために使います。
> - 通知:ロック画面などでタイマーのボタンと経過時間を出し、予定やタイマーを知らせるために使います。
> - アラームとリマインダー:その知らせを遅れずに届けるために使います。
> - 再起動の知らせの受信:端末の再起動のあと、通知と知らせを預け直すために使います。
> どの権限も、利用者が端末の設定でいつでも外せます。
>
> **4. 情報の削除**
> 本アプリの「設定 › このアプリについて › すべてのデータを消す」で消せます。アンインストールしても、端末に保存された情報はすべて削除されます。Google のクラウドにも残りません。
>
