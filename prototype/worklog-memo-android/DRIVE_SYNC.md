# ドライブで同期:Google Cloud の準備

「ドライブで同期」は、利用者の Google ドライブの、このアプリ専用の隠しフォルダ(appDataFolder)に
`worklog-sync.json` を一つ置き、ブラウザ版とアプリ版が読み書きする仕組みです。
Google に「このアプリが、利用者の許可を得てドライブの隠しフォルダを使う」ことを届け出るため、Google Cloud にプロジェクトを一つ作ります。
ブラウザ版とアプリ版は、**同じプロジェクト**の中の鍵(OAuth クライアント)を使います。同じプロジェクトだから、同じ隠しフォルダを見られます。

お金はかかりません(Drive API の無料の範囲で足ります)。

## 1. プロジェクトを作る

1. https://console.cloud.google.com/ を開き、自分の Google アカウントでログインする。
2. 画面の上の「プロジェクトを選択」(または今のプロジェクト名)を押し、「新しいプロジェクト」を押す。
3. プロジェクト名を `worklog-memo` にして「作成」を押す。できたら、上でそのプロジェクトを選んでおく。

## 2. Google Drive API を使えるようにする

1. 左上の「≡」から「API とサービス」→「ライブラリ」を開く。
2. 「Google Drive API」を検索して開き、「有効にする」を押す。

## 3. ログインの画面(同意画面)を作る

1. 「≡」→「API とサービス」→「OAuth 同意画面」を開く(「Google Auth Platform」の画面に移る)。
2. 「開始」を押し、次のように入れて進める。
   - アプリ名:`作業記録メモ帳`
   - ユーザー サポートメール:自分のアドレス
   - 対象:**外部**
   - 連絡先メールアドレス:自分のアドレス
3. 規約に同意して「作成」を押す。
4. 左の「データアクセス」→「スコープを追加または削除」を押し、一覧から
   `.../auth/drive.appdata`(「Google ドライブ内のアプリ自身の構成データの表示、作成、削除」)にチェックを入れて「更新」→「保存」。
5. 左の「対象」を開き、「テストユーザー」の「＋ ADD USERS」で自分の Gmail アドレスを足す。
   - 「テスト」のあいだは、ここに足した人(100 人まで)しかログインできません。

## 4. 鍵(OAuth クライアント)を作る

左の「クライアント」→「＋ クライアントを作成」で、次の二つ(Play に出すときは三つ)を作ります。

### ブラウザ版(GitHub Pages)
- アプリケーションの種類:**ウェブ アプリケーション**
- 名前:`ブラウザ版`
- 承認済みの JavaScript 生成元:`https://noneedsgames-ui.github.io`
- 「作成」を押すと **クライアント ID**(`…apps.googleusercontent.com` で終わる文字)が出る。**これを Claude に渡す**(`index.html` の `GOOGLE_WEB_CLIENT_ID` に入れる)。クライアント ID は公開されても困らないものです。クライアント シークレットは使いません。

### アプリ版(直接入れる試作版)
- アプリケーションの種類:**Android**
- 名前:`アプリ(試作)`
- パッケージ名:`com.noneedsgames.worklogmemo.dev`
- SHA-1 証明書フィンガープリント:`86:89:32:A0:80:8C:39:2B:76:05:AB:82:CB:58:84:EC:36:B1:E8:28`(`app/debug.keystore` のもの)

### アプリ版(Google Play の版)— Play に出すときに
- アプリケーションの種類:**Android**
- パッケージ名:`com.noneedsgames.worklogmemo`
- SHA-1:Play Console の「テストとリリース › アプリの完全性 › アプリ署名」にある「アプリ署名鍵の証明書」の SHA-1。
  アップロード鍵の SHA-1 でも一つ作っておくと、内部テストで直接確かめられます。

アプリ版には ID を入れる場所はありません。Google がパッケージ名と署名から見分けます。

## 5. 広く配るとき

- 「対象」で「アプリを公開」を押すと、テストユーザー以外もログインできるようになります。
- 公開の前に、「ブランディング」にプライバシーポリシーのページの URL などを入れます(GitHub Pages に置けます)。
- 確認(審査)が要るかどうかは、公開のときに画面に出ます。要るあいだは、ログインで「このアプリは Google で確認されていません」と出ることがあります。

## うまくいかないとき

- アプリ版で「うまくいきませんでした(error:10: …)」:Android のクライアントのパッケージ名か SHA-1 が、入れたアプリと合っていません。
- ブラウザ版でログインの窓がすぐ閉じる・`origin_mismatch`:承認済みの JavaScript 生成元が `https://noneedsgames-ui.github.io` になっているか確かめる(末尾に `/` を付けない)。
- 「アクセスをブロック」:テストのあいだは、テストユーザーに足したアカウントでしかログインできません。

## 開発のメモ

- パソコンの Gradle が新しい部品(play-services-auth)を落とすとき、HTTPS の確認で失敗したら、Windows の証明書を使わせる:
  `.\gradlew.bat "-Djavax.net.ssl.trustStoreType=Windows-ROOT" "-Dorg.gradle.jvmargs=-Xmx2g -Dfile.encoding=UTF-8 -Djavax.net.ssl.trustStoreType=Windows-ROOT" installDebug`
  (ウイルス対策ソフトが HTTPS を検査していると起きる。一度落とせば、あとは手元に残る)
