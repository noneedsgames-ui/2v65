# 作業記録メモ帳(Web試作)

要件定義書「作業時間記録メモ帳アプリ 要件定義書」(2026-11-01)を、スマホのブラウザですぐ試せる形にした試作。
`index.html` 一枚で動く。ネイティブ版(Kotlin / Jetpack Compose / Room)に移る前に、画面の流れと使い心地を確かめるためのもの。

## 要件との対応

| 要件 | Web試作での扱い |
|---|---|
| 起動直後に入力できるメモ | メモ画面の本文欄から始まる。600ms ごとに自動保存 |
| 階層タブ | 入れ子のツリー表示。▾/▸ で開閉、選択中のタブの「＋子」で子を追加、末尾から最上位に追加。⋯ から名前変更・並べ替え・階層の移動・削除 |
| タグ・関連付け・横断検索 | 対応。`#タグ` でタグ検索 |
| テンプレート(素材・アイテム・設定) | 対応。中身は設定で編集できる |
| 作業時間の自動記録 | ページが前面にある間を記録(Page Visibility API)。無操作では止めない |
| 日別・週別・月別の集計 | 対応。作業時間と妨害アプリを並べたグラフと表 |
| タイマー | ストップウォッチ/ポモドーロ、ラベル付き。作業時間には加算しない |
| 予定 | 日別・週別の一覧、登録・編集・削除、何分前通知 |
| 妨害アプリの使用時間 | **自動取得できない**ため、記録画面で分数を手入力する |
| 予定の通知 | **ページを開いている間だけ**音と表示で知らせる |

## 保存

端末内(localStorage)へ即時に保存し、claude.ai 上で開いた場合は本人専用の領域へも同期する。
