# 作業記録メモ帳(Web試作)

要件定義書「作業時間記録メモ帳アプリ 要件定義書」(2026-11-01)を、スマホのブラウザですぐ試せる形にした試作。
`index.html` 一枚で動く。ネイティブ版(Kotlin / Jetpack Compose / Room)に移る前に、画面の流れと使い心地を確かめるためのもの。

## 要件との対応

| 要件 | Web試作での扱い |
|---|---|
| 起動直後に入力できるメモ | 前回書いていた行(なければ最後の行)から書ける。自動保存 |
| メモとボード | 上の「＋ 新しいメモ」でメモをいくつでも作れる(名前を付けなければ1行目が名前)。「◧ ボード」にはすべてのメモがカードで並び、ドラッグで自由に配置、右下の●を別のカードへ引くと矢印(ラベル・片向き/両向き/線だけ)、空いた所で離すと新しいメモをつないで作る。長押しで色・名前・削除。ドラッグで移動、二本指・ボタンで拡大縮小。「◯ 囲む」で指で描いて囲むと、その形(描いた形の特徴を残しつつ、ある程度ならして整えた形)がファイルになる。線の内側にあるカード・丸が中身で、いくつもの丸に入るときはいちばん内側の丸に属する(入れ子)。カードや丸を線の内側へドラッグすると追加され、丸はそれが収まるようにふくらむ(入れ子なら外側の丸も)。外へ出すと抜ける。名札のドラッグで中の丸・カードごと移動、名札の●で丸同士・丸とカードを矢印でつなぐ、タップで名前・色・形を描き直す・丸を消す(中身はひとつ外側へ)。一定以上縮小すると、カードはタイトルだけになる。丸の名札のメニュー「中を整列」で、中のカードと丸をツリーの順に行と列へそろえ、丸を中身に合う形にする(中の丸から順に)。ファイルごとに色が自動で付き、中のメモはその色で淡く塗られる(設定で切れる)。矢印は自動で色分け(別のファイルのメモ同士=緑、ファイル同士=青で少し太く。設定で色・太さを変えられる)。メモ画面の ☰ で、ファイルとメモの入れ子のツリーを左に出し、長押しで並べ替え・ファイルへの出し入れができる(ボードのカードや丸も、そのファイルの中へ動いて反映され、移した先と元のファイルの中は自動で整列する。設定で切れる)。ボードは上の「図|リスト」で、カードの図と、一段ずつ開くリストを切り替えられる(下の「ボードのリスト」)。メモ画面の「つながり」の帯に、そのメモ(と入っているファイル)の矢印が「→ 行き先」「← 来た元」で並び、押せばそのメモへ移る(先がファイルなら中のメモを選ぶ。「‹ 戻る」で一つ前へ)。ファイルの名札を別の丸の上で離すと、大きさに関係なくその中に入って丸がふくらむ。ファイルのメニュー「この中に新しいファイル」、ツリーとリストの「＋ ファイル」で空のファイルも作れる。メモ画面の上の帯はメモの名前と大きな「◧ ボード」ボタンだけで、所属は左のツリーで見る。検索と行の関連付けはメモをまたいで効く |
| 行の形式 | 行ごとに「箇条書き・チェック・番号付き・タイムライン・見出し・補足・コード」を選べ、一つのメモの中で混ぜられる(操作バーの「形式」)。Markdown の記号(`[] ` `[x] ` `1. ` `@時 ` `# ` `> ` ```` ``` ````)を行の頭で打っても変わる(全角も可)。印は箇条書きの「•」と同じ場所に置き、タイムラインは続く行どうしを一本の線でつなぐ。改行で同じ形式が続き、空のまま改行するとふつうの行に戻る。Markdown や ☐/☑ の文章を貼ると形式として読み込む |
| コピー・選択・削除 | 上の「コピー」でメモ全体を、記号つきの文章か Markdown にしてコピー。「選択」で行を複数選び、まとめてコピー・形式の変更・削除。操作バーの「削除」で1行削除。削除の直後は「元に戻す」が出る |
| 色を選ぶ所の虹色の丸 | 色を選べる所(カード・丸・矢印・文字の色・作業の種類)には、並びの最後に虹色の丸があり、押すと色の表(12色相×6段+灰色12段)と #rrggbb の入力欄が開く。選んだ色はその並びに丸として足され、選んだことになる。色は決まった名前か #rrggbb で持ち、#rrggbb のクラスは使うときに `#customColors` へ足す(`ck()`) |
| 作業の種類の色 | 設定の「作業の種類」で、名前の前の色の点を押すと色を選べる(「自動」は並び順の色)。グラフ・タイマー・記録でその色を使う(`workTypes[].color`) |
| 広い画面 | 幅 900px 以上では、タイマー・記録・予定・設定を真ん中の 860px に寄せる。1200px 以上では、設定のカードを二列に並べる |
| 太字と文字の色 | 書いている行で文字を選び、操作バーの「B」で太字(パソコンは Ctrl+B でも)。「色」は押すたびに 赤→橙→黄→緑→青→紫→灰→色なし と変わり、長押しで色の一覧(虹色の丸から色の表)を開く。「色」のボタンはいま書く文字の色で、「B」は太字の間は押した見た目で出る。選ばずに押すと、これから書く文字に付く(太字の続きで「B」を押すと、そこから太字をやめる。色の文字の中で「色」を押すと、その色を変える)。太字や色の文字の終わりに続けて書いた文字は、同じ形になる。行の文字には記号を入れず、範囲 `n.f = [{s, e, b:1} | {s, e, c:"赤"|"#rrggbb"}]` で持ち、書き足し・消し・改行・行をつなぐときに範囲もずらす(`setT`・`editFmt`)。書いている間も記号は見えず、文字を透明にした入力欄の上に、同じ位置で色付きの文字を重ねる(太字は字の幅が変わらないよう縁取りで見せる)。以前の形(`**太字**` と `{赤:文字}`)は、メモを開いたときに範囲へ直す。Markdown のコピーでは太字を ** で囲み、色は外す |
| 階層構造 | タブは廃止。記入欄そのものが入れ子のアウトライン(1行=1項目)。改行で次の行、→/Tab で字下げして子に、←/Shift+Tab で戻す(→ ← は操作バーのボタン。パソコンのキーでは Tab/Shift+Tab か Alt+Shift+→/←、Alt+Shift+↑/↓ で行の入れ替え)。行頭の ▾/▸ で畳む。行を長押し(約0.35秒)して持ち上げ、ドラッグでサブツリーごと移動(行頭の ▾/• は長押しなしで動かせる)(行の上部=前へ、中央=子へ、下部=後ろへ。指を右へ約32px寄せるごとに一段深く=子に、左で浅くなる)。「この項目だけ表示」で絞り込み。字下げ付きの文章を貼るとそのまま入れ子になる |
| タグ・関連付け・横断検索 | 行の中に `#タグ` と書くとタグ。行どうしを関連付けると双方にリンクが出る。全行を横断して検索 |
| テンプレート(素材・アイテム・設定) | 字下げ付きのひな形を行として挿入。ひな形の【…】は灰色で出し、その行を選ぶと【…】ごと選ばれ、消さずに打てば入れ替わる。行末で改行すると、次の行がひな形の「項目:」でまだ空なら、新しい行を作らずその:の後へ進む。設定で追加・名前変更・削除・中身の編集ができる |
| 作業時間の自動記録 | ページが前面にある間を記録(Page Visibility API)。無操作では止めない |
| 日別・週別・月別の集計 | 対応。作業時間と妨害アプリを並べたグラフと表。日別ではアプリを開いていた時間を1時間ごとの棒グラフで出す |
| マスコット「ミモザ」 | **当面はどちらの版にも出さない**(`SHOW_MIMOZA = false`。戻すときは `NATIVE` にする)。以下は戻したときの動き:**Android アプリ版だけ**。記録画面と初めの案内で吹き出しでしゃべる(画像は `mimoza.png` を埋め込まず、ビルドで assets に写して読む。ブラウザ版には画像もミモザも出ない)。はじめてのときはあいさつ、ふだんはその期間の記録(タイマーの時間、いちばん多い種類、目標、妨害アプリ)に合わせて話し、使い方のひとことも添える。タップで次のセリフ。`Mimoza.say(セリフの配列, 終わったとき)` でどの画面からでもしゃべらせられるので、チュートリアルにも使える |
| 作業の種類と積み上げグラフ | 時間を分ける箱が「作業の種類」。初めは「計画メモ」だけで、作業に数えるアプリを足すとその名前の種類ができる。設定で足す・名前を変える・消す・並べ替える(色は登録順の8色、9つ目からはほかと離れた色を順に作る。点を押して自分で選べる。いくつあっても種類ごとに分かれる)。このアプリを開いていた時間と、各作業アプリの時間は、設定で選んだ種類に入る。タイマーからもどの種類でも選べる。記録画面の主役は種類ごとの積み上げ棒グラフ(日別は1時間ごと、週・月別は1日ごと)と合計。タイマーと重なる時間はタイマーの種類に数え、二重に数えない。記録はタップで種類や時刻を直せる。アプリの使用時間は下の折りたたみへ |
| メモのタグ | 上の「タグ」で、メモそのものにタグを付け外しする(行の中の #タグ とは別)。タグはつながりの帯・ボードのカード・ボードのリストに出て、押すと同じタグのメモの一覧から開ける。検索の「#タグ」でもそのタグのメモが出る。ファイル(丸)の設定「このファイル内のメモにタグを追加する」をオンにすると、その丸(中の丸も)に入っているメモに、ファイルと同じ名前のタグが付く(名前は変えられる。丸から出すと外れる。📁 の印で、自分で付けたタグと区別して出る) |
| 複数のボード | ボード画面の上の帯で、ボードを切り替え・作成する。「◧ メイン」にはすべてのメモが自動で並ぶ。新しいボードには「＋ 入れる」で、メモを選んで置いたり、ほかのボードのファイル(丸)を中のメモ・中の丸・その間の矢印ごと写したりできる。同じメモを複数のボードに置け、丸・矢印・位置・表示の倍率はボードごとに別々。カードのメニューで「ほかのボードにも置く」「このボードから外す(メモは残す)」。いまのボードの名前の ▾ で、名前・並び順・削除(メモは消えない) |
| ボードのリスト | 「リスト」は、一段ずつ開く一覧。ボードがいくつもあれば、いちばん外はボードの一覧で、ボードはそれぞれ大きなファイルとして並ぶ(このときは上のボードの切り替えを隠す。「＋ ボード」もここ)。ボードやファイルを押すと、その中のファイルとメモの一覧に入れ替わり、上に「◧ ボード › 📁 ファイル」と道すじが出て、「‹ 戻る」で外へ。メモを押すと開く。「⋯」でボード・ファイル・メモのメニュー。開いているファイルで右上の「＋ メモ」を押すと、そのファイルの中にメモを作ってすぐ書ける。以前の「タグ」(タグの円が重なる図)は廃止し、分けるのはファイルで行う |
| 一つのメモを二つのファイルに(分身) | カードを長押しして「ほかのファイルにも入れる」でファイルを選ぶと、そのファイルの中に分身(📎・点線のカード)を置く。中身は同じメモで、どちらで書いても同じ。左の一覧・ボードのリスト・ファイルのタグ・つながりの帯(ファイルの矢印)では、そのファイルにも入っている扱いになる。分身は押すと元のメモを開き、ボードで動かして別のファイルへ移せる。どのファイルにも入らない所へ出すか、長押しの「外す」でなくなる(メモは残る)。メモを消すと分身も消える。持ち方は `board.alias = { 分身id: { m, x, y } }` と、入っている丸の `amembers` |
| メモのリンク | 行の中で `/` を打つと名前の候補が出て、選ぶとリンクになる(日付の 11/1 や A/B では出さない。選ばなければ / はただの文字)。中身は `[[メモの名前]]` で、`[[` から打っても同じ。タップでそのメモへ飛ぶ(名前だけでは飛ばない)。候補の最後の「＋「名前」を新しいメモに」を選ぶと、その名前のメモを作ってリンクにする(書いている所はそのまま)。まだないメモへのリンクを押しても、その場で作れる。つながりの帯に、リンク先(↗)とリンク元(↙)も出る |
| タイマー | ストップウォッチ/ポモドーロ、作業の種類とラベル付き。タイマーの下の「タイマーの設定」で、ポモドーロの集中・休憩の長さ、1日の目標、止め忘れを尋ねるまでの時間(アプリ版は集中ブロックとロック画面の通知も)を変える(以前は設定の画面にあった)。今日のタイマー合計の欄はなくした。記録の「作業」に作業の種類ごとに入り、アプリを開いていた時間や作業アプリとの重なりは二重に数えない。タイマー中に妨害アプリを画面で覆って止めるのは Android アプリ版だけ |
| ドライブで同期 | 設定の「ドライブで同期」で Google アカウントにログインすると、利用者の Google ドライブの、このアプリ専用の隠しフォルダ(appDataFolder)の `worklog-sync.json` を通して、ブラウザ版・アプリ版・別の端末のデータを同じに保つ。開いたとき・書き換えて1分ほどたったとき・閉じるとき・開いている間は3分おきに同期する。その端末で初めての同期は「データの引っ越し」と同じく両方を残して合わせ、以後は文書ごとに新しい方を採る(作業の記録は両方の分を合わせる)。消したメモは、消した時刻より後に書き換えていなければ、ほかの端末でも消える。ブラウザ版は1時間ごとにログインが切れるので、上の帯の「☁ ログインして同期」で入り直す。準備は `prototype/worklog-memo-android/DRIVE_SYNC.md`。ブラウザ版は `GOOGLE_WEB_CLIENT_ID` を入れるまで出ない。claude.ai の試作ページでは出ない |
| ブラウザ版 | 同じ `index.html` を、GitHub Pages(https://noneedsgames-ui.github.io/worklog-memo/、公開リポジトリ `noneedsgames-ui/worklog-memo`)と claude.ai の試作ページ(https://claude.ai/artifact/92TaFhMc1gCyY58VBR1CsZ)で開く。claude.ai 以外では同期の説明を出さない。`NATIVE` でないときは、端末のアプリを読む機能(妨害アプリ・作業に数えるアプリの欄、使用状況や集中モードの案内、集中中の注意、アプリの使用時間の折りたたみ、自動バックアップ、端末の許可)を出さず、「このアプリ」を「このページ」と書く。データはアプリ版とは別 |
| 予定 | 日別・週別の一覧、登録・編集・削除、何分前通知 |
| 妨害アプリの使用時間 | Android アプリ版の設定「端末のアプリから選ぶ」で選んだアプリの時間を、端末から自動で読む。名前や分数の手入力はしない。**ブラウザ版からは読めない**ので、以前に記録した時間だけを出す |
| 作業に数えるアプリ | Android アプリ版で選んだアプリ(お絵描き・ドット絵など)の使用時間を作業時間に足す。読み方は妨害アプリと同じ |
| 予定の通知 | ブラウザ版は**ページを開いている間だけ**音と表示で知らせる。Android アプリ版は閉じていても通知で知らせる |
| ダークモード | 設定の「画面の色」で、端末に合わせる/ライト/ダークを選ぶ。端末ごとの好みなので、書き出しには入らない。見た目は白・黒・灰色を基調にし、強調(ボタン・チェック・リンク)はライトでは黒、ダークでは白。色は作業の種類や収支の分類など、見分けに要る所だけに使う |
| 収支 | 「予定」のページの「収支」。「プロジェクト」では、作るものごとに費目と予算を立て、実際の支出と比べて残りと超過を出す。「月別」では月ごとの収入・支出・残り、分類別の内訳、合計と分類ごとの予算、この半年の支出。毎月の分類は足す・名前を変える・消す・並べ替えるができ、入力画面からも編集できる。固定費は決まった日に自動で記録する(手で消した月は作り直さない) |
| 長期計画 | 「予定」のページの「長期計画」。目標に期間と節目を付け、進みぐあいと残りを出す。一覧と年表で見られる。期限と節目は予定の日別にも出て、Android ではその日の朝9時に通知する。年表を横に動かしても、計画の名前は棒の見えている所の左に寄せて出す |
| カードの外枠 | カードのメニューで、外枠(通常・点線・太線・二重・なし)と形(通常・四角・丸く・菱形)を変えられる。ボードごとに別々 |
| 矢印を二回タップで消す | 一回でメニュー、すばやく二回で消す。直後なら「元に戻す」で戻せる |
| 全体の整列 | ボードの「整列」で、丸の中をそろえてから、いちばん外のカードと丸を行と列に並べる。直後なら「元に戻す」で戻せる |
| メモのコメント | メモ画面の「コメント」で、本文とは別に一つ書き添える。ボードのカードのそばに出て、検索でも見つかる |
| 画面の編集 | 設定の「編集モード」か、下のタブの長押しで入る。下のタブと「予定」の中の項目を、ドラッグで入れ替え、✕ で消せる。「項目の一覧」で戻す・名前を変える・初期の配置に戻す。消しても記録やデータは消えない。配置は meta.prefs.layout |
| 自分で作る項目 | 編集モードの「＋ 新しい項目」で、名前と印を決め、チェック・番号・タイムラインなどのメモの要素で項目を作って下のタブに置く。中身はふつうのメモなので、ボードや検索にも出る。今あるメモを項目にもできる |
| タイマーの止め忘れ | 計り始めから決めた時間(初期は3時間、設定で変更・停止)が過ぎると「まだ計っている / いま止める / この時刻で止める」を尋ねる。時刻を直して止めると、それより後に自動で積んだポモドーロの区切りも取り消す |
| 作業時間の訂正(タイマーの記録の修正) | 欄の名前は「作業時間の訂正」。記録画面の日別で、記録をタップして種類・ラベルのほか始まりと終わりの時刻を直せる。計り忘れた分は「＋ 記録を足す」で足せる(ほかの記録と重なる時刻は入れられない) |
| ドラッグで消す | 行、メモ、ファイル(丸)を動かしている間、下にゴミ箱が出る。そこへドラッグすると消え、直後なら「元に戻す」で戻せる。メインのボードではメモを削除し(30日はゴミ箱に残る)、ファイルは中の丸とメモごと削除する。ほかのボードでは、メモ自体は消さずそのボードから外すだけで、そのときのゴミ箱は黄色。丸のメニューの「丸だけ消す」なら中身は残る |
| ゴミ箱 | 消したメモは30日間残り、設定の「ゴミ箱」から戻せる(矢印や丸の所属は戻らない) |
| すべてのデータを消す | 設定の「このアプリについて」から。「消す」と入力して確かめる。同期先の分も消す |
| 自動バックアップ(Android) | 設定の「データの引っ越し」で保存先のファイル(Google ドライブなど)を一度選ぶと、アプリを開いたときに一日に一度、最新のデータで上書きする。送信はドライブのアプリが行うので、このアプリにネットワークの権限は要らない。データが空のときは上書きしない。戻すときは「読み込む」でそのファイルを選ぶ |
| 書き出しの催促 | 同期していないとき、最後の書き出しから30日が過ぎると一度勧める(断ると7日は出さない。設定で切れる) |
| 許可の案内 | 使用状況・重ね表示・通知・アラームとリマインダーの許可は、要る場面で理由を説明してから設定の画面へ案内する |
| 初めの案内(チュートリアルのメモ) | 初めて開いたときは、空のメモの代わりに「チュートリアル」のメモ(id `tutorial`)を置いて開く。たたみ方・入れ子・書き方・形式・太字と色・リンク・ボード・記録・データの順に、ふつうのメモとして書いてあり、触りながら覚えられる。中身は `tutorialLines()`(行頭の空白2つで1段、印 ・☐☑■、`**太字**` と `{赤:色}`)。消しても、設定の「チュートリアルのメモを開く」でまた置ける。アプリ版は、最初に通知の許可を尋ねる。プライバシーポリシーも設定から読める |
| ボードの整列 | 「整列」(全体)とファイルの「中を整列」は、矢印で一列につながったメモやファイル(枝分かれも輪もないもの)を、矢印の向きの順に一行に並べ、高さの真ん中をそろえて矢印をまっすぐにする。ほかは行と列に並べる |
| 丸がふくらむときの巻き込み | ファイルの中に新しいファイルを作るとき、中に空きがなければ、外のすぐそばで、ほかの丸やカードにかからない所(下・右・左・上の順)に置いてから外側をふくらませる。ボードでカードや丸を丸の中へ落としたときと、新しいファイルを作ったときは、ふくらんだ丸が関係ないファイルやメモを巻き込んでいたら、元のファイルへ戻す(`reconcileTree`)。「整列」は、ボードの縦横の比に合わせて列の数を決める。「全体」は 8% まで縮めて、たくさんのファイルも一度に見渡せる |
| 名前の並び | 左の一覧・タグなどの名前の並びは、数を数として比べる(「ファイル2」が「ファイル10」より前) |
| ボードのボタン | 囲む・整列・＋・−・全体は、右の端に縦に並べる。「全体」はボタンの列にかからない幅で合わせる |
| 入力の上限 | メモの行のほかは、文字数に上限がある(名前 20〜80 字、絞り込み・検索 40 字、予定の補足やプロジェクトのメモ 500 字、テンプレートの中身 2000 字など)。金額は 9億9999万9999円まで |
| データの引っ越し | 設定の「データの引っ越し」で、メモ・ボード・予定・設定・作業の記録を JSON ファイル(または文章のコピー)に書き出し、ブラウザ版とアプリ版のあいだなどへ移せる。読み込みは今のデータに合わせる:記録は両方の分を足し、同じメモの中身が違えば新しい方を残して古い方を「(別の版)」として残す。同じ名前の作業の種類・アプリは一つにまとめる。消したメモは、読み込んだファイルに入っていれば戻る |

## 保存

端末内(localStorage)へ即時に保存し、claude.ai 上で開いた場合は本人専用の領域へも同期する。
初めて同期する端末では同期先の内容を正とし、作業の記録(月ごとの区間・タイマー・使用時間)は両端末の分を合わせる。

## Android アプリ版

`prototype/worklog-memo-android/` は、この `index.html` をそのまま画面に使う Android アプリ(Kotlin)。
ブラウザではできない次の三つを、端末の機能で足している。

| 機能 | しくみ | 必要な許可 |
|---|---|---|
| ほかのアプリの使用時間を読む | 使用状況データ(UsageStatsManager)の前面・背面の出来事から、日ごとの前面時間を数える。設定の「端末のアプリから選ぶ」で選んだアプリは、記録画面で「自動」と出る | 使用状況へのアクセス |
| ホーム画面のウィジェット「作業タイマー」 | 止まっているときは「▶ ストップウォッチ」「▶ タイマー」、計っているときは経過時間(タイマーは集中・休憩の終わる時刻)と「■ 止める」を出す。ボタンはアプリを開いて、そのまま始める・止める(記録は画面側でつける)。タイマーの様子は画面から `Android.timerState` で受け取る。ブラウザ版でも `#start=stopwatch`・`#start=pomodoro`・`#stop` 付きのURLで同じことができる | なし |
| ロック画面の通知 | 止まっているときは「▶ 開始」(ストップウォッチ)、計っているときは大きな経過時間と「■ 止める」を出す。ボタンは通知の本文にあるので、折りたたまれていても押せる。アプリを開かず、ロックを解かずに効く。押した時刻を貯めておき、次に画面が動いたときに記録へ移す。ここから始めても妨害アプリのブロックがかかり(最大5分)、許可が足りず始められないときは通知に警告を出す。タイマー(ポモドーロ)は始められないが、計っている様子と「止める」は出る。設定の「ロック画面に通知を出す」で切れる | 通知(Android 13 以降) |
| 妨害アプリの使用時間を隅に出す | 設定でオンにすると(初期はオフ)、選んだ妨害アプリが前面にある間、そのアプリの今日の合計時間を画面の隅に秒まで出す。タイマーとは関係なく動く。触れない表示で、下のアプリの操作は妨げない。動いている間は通知が一つ出る(`UsageOverlayService.kt`) | 使用状況へのアクセス、他のアプリの上に重ねて表示 |
| 閉じていても届く知らせ | 予定の時刻、ポモドーロの区切り、タイマーの止め忘れを通知で知らせる(`Alarms.kt`)。目覚ましは近い一件だけを端末に預け、鳴ったら預け直す。前面で使っている間は画面の側で知らせる。許可がなくても届くが、数分遅れることがある | 通知、アラームとリマインダー(任意) |
| タイマー中に妨害アプリを使えなくする(試験運用) | タイマーを始めると前景サービスが動き、妨害アプリが前面に出たら画面全体を覆う。**いちどに最大5分**で自動で止まる(タイマー画面からかけ直せる) | 使用状況へのアクセス、他のアプリの上に重ねて表示 |

- ビルドは GitHub Actions(`.github/workflows/worklog-memo-apk.yml`)。Actions の「Run workflow」で手で動かしたときだけ APK を作る。できたものは実行結果の Artifacts から落とす
- 直接入れる APK は試作用の固定のデバッグ鍵(`app/debug.keystore`)で署名し、「作業記録メモ帳(試作)」(`.dev`)という別アプリとして入る。前の版の上から入れれば、データは残る
- Google Play の内部テストに出す AAB は、Secrets のアップロード鍵で署名する。手順と Play Console の文案は `prototype/worklog-memo-android/PLAY_RELEASE.md`
- データは端末内に置く(claude.ai への同期も、Android のクラウドバックアップもない。利用者が選んだ保存先へは書き出せる)。ブラウザ版のデータとは別で、設定の「データの引っ越し」で移せる
