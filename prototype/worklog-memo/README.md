# 開発メモ(Web試作)

要件定義書「作業時間記録メモ帳アプリ 要件定義書」(2026-11-01)を、スマホのブラウザですぐ試せる形にした試作。
`index.html` 一枚で動く。ネイティブ版(Kotlin / Jetpack Compose / Room)に移る前に、画面の流れと使い心地を確かめるためのもの。

## 要件との対応

| 要件 | Web試作での扱い |
|---|---|
| 起動直後に入力できるメモ | 前回書いていた行(なければ最後の行)から書ける。自動保存 |
| メモとボード | ボードがメモの親で、下のタブの「メモ」を押すと、まずボード(メモがカードで並ぶ。図とリストを切り替えられる)が開く。カードやリストの行を押すとそのメモが開き、メモの左上の「← ボード」(Android の戻るボタンも)でボードに戻る。アプリを開いたときもボードから始まる。ボードの「＋ メモ」は、新しいカードを置いてカードの上で表題を書く(中身はカードを押して開いて書く。空のまま決めると消える)。初めてのボードには、使い方(開く・動かす・矢印・囲む・マップ・拡大縮小・ゴミ箱)を箇条書きで出す。上の「＋ 新しいメモ」でメモをいくつでも作れる(名前を付けなければ1行目が名前)。「◧ ボード」にはすべてのメモがカードで並び、ドラッグで自由に配置、右下の●を別のカードへ引くと矢印(ラベル・片向き/両向き/線だけ)、空いた所で離すと新しいメモをつないで作る。長押しで色・名前・削除。ドラッグで移動、二本指・ボタンで拡大縮小。「◯ 囲む」で指で描いて囲むと、その形(描いた形の特徴を残しつつ、ある程度ならして整えた形)がグループになる。線の内側にあるカード・丸が中身で、いくつもの丸に入るときはいちばん内側の丸に属する(入れ子)。カードや丸を線の内側へドラッグすると追加され、丸はそれが収まるようにふくらむ(入れ子なら外側の丸も)。外へ出すと抜ける。名札のドラッグで中の丸・カードごと移動、名札の●で丸同士・丸とカードを矢印でつなぐ、タップで名前・色・形を描き直す・丸を消す(中身はひとつ外側へ)。一定以上縮小すると、カードはタイトルだけになる。丸の名札のメニュー「中を整列」で、中のカードと丸をツリーの順に行と列へそろえ、丸を中身に合う形にする(中の丸から順に)。グループごとに色が自動で付き、中のメモはその色で淡く塗られる(設定で切れる)。矢印は自動で色分け(別のグループのメモ同士=緑、グループ同士=青で少し太く。設定で色・太さを変えられる)。メモ画面の ☰ で、グループとメモの入れ子のツリーを左に出し、長押しで並べ替え・グループへの出し入れができる(ボードのカードや丸も、そのグループの中へ動いて反映され、移した先と元のグループの中は自動で整列する。設定で切れる)。ボードは上の「図|リスト」で、カードの図と、一段ずつ開くリストを切り替えられる(下の「ボードのリスト」)。メモ画面の「つながり」の帯に、そのメモ(と入っているグループ)の矢印が「→ 行き先」「← 来た元」で並び、押せばそのメモへ移る(先がグループなら中のメモを選ぶ。「‹ 戻る」で元のメモへ)。本文のリンク([[名前]])だけのつながりはここには出さず、リンクは本文の中で押して移る。グループの名札を別の丸の上で離すと、大きさに関係なくその中に入って丸がふくらむ。グループのメニュー「この中に新しいグループ」、ツリーとリストの「＋ グループ」で空のグループも作れる。メモ画面の上の帯はメモの名前と大きな「◧ ボード」ボタンだけで、所属は左のツリーで見る。検索と行の関連付けはメモをまたいで効く |
| 行の形式 | 行ごとに「箇条書き・チェック・番号付き・タイムライン・見出し・補足・コード」を選べ、一つのメモの中で混ぜられる(操作バーの「形式」)。Markdown の記号(`[] ` `[x] ` `1. ` `@時 ` `# ` `> ` ```` ``` ````)を行の頭で打っても変わる(全角も可)。印は箇条書きの「•」と同じ場所に置き、タイムラインは続く行どうしを一本の線でつなぐ。タイムラインの時は、ふだんは時・分のホイールで時刻を選び、上のタブで月日・年月日の形にも変えられる(「第1章」のような言葉も書ける)。時がまだない行で開くと、その前で時が入っている行の一つ後ろ(時刻なら1時間後、月日なら1日後、年月日なら1か月後)を初めに出す。タイムラインの行を同じ並びの中で入れ替えても、時はその位置に残り中身だけが動く。入れ子の線や、たたんだときの項目数は出さない。改行で同じ形式が続き、空のまま改行するとふつうの行に戻る。Markdown や ☐/☑ の文章を貼ると形式として読み込む |
| コピー・選択・削除 | 上の「コピー」でメモ全体を、記号つきの文章か Markdown にしてコピー。「表にする(列を自分で決める)」は、列の名前(凡例)を「,」か「、」で並べると、その形の表にする。1列目は項目そのもの、「親」の列は一つ上の行(見出しなど)、ほかの列はその項目のすぐ下の「列の名前:値」の行の値で、すぐ下にそうした行がある項目が1行になる。メモの中の「名前:」を候補のボタンに出し、下見の表で確かめてから、表としてコピーか CSV で保存する(凡例はメモごとに覚える)。「表(字下げを列で)」は一段下がるごとに右の列へずらした表で、スプレッドシートに貼るとそのまま表になる(タブ区切り)。「CSV ファイルに保存」は同じ表を .csv にする(Excel 用に BOM 付き。アプリは保存先を選ぶ)。チェックは ☐☑、タイムラインの時は [時] を本文の前に添える。「選択」か、行を長押しして動かさずに離すと複数選択に入り、タップで行を足し外しして(選んだ行は行の地を濃く、一緒に動く下の行は淡く塗って示す。四角の印は出さない。選択中に長押ししてそのままなぞると、なぞった範囲をまとめて選び、選んだ行から始めればまとめて外す。上下の端へ寄せると送りながら選ぶ)、まとめてコピー・形式の変更・削除。選んだまま ← → ↑ ↓ で、選んだ行を下の行ごと一度に一段戻す・字下げ・上下へ動かせる。操作バーの「削除」で1行削除。削除の直後は「元に戻す」が出る |
| 元に戻す・やり直す | メモの上の「↶」で一つ前の姿に戻し、「↷」でやり直す。書いた文字は手を止めたところで、行の移動・字下げ・削除などは一つずつ覚える(メモごとに100まで。ほかのメモを開くと空になる) |
| 色を選ぶ所の虹色の丸 | 色を選べる所(カード・丸・矢印・文字の色・作業の種類)には、並びの最後に虹色の丸があり、押すと色の表(12色相×6段+灰色12段)と #rrggbb の入力欄が開く。選んだ色はその並びに丸として足され、選んだことになる。色は決まった名前か #rrggbb で持ち、#rrggbb のクラスは使うときに `#customColors` へ足す(`ck()`) |
| 作業の種類の色 | 設定の「作業の種類」で、名前の前の色の点を押すと色を選べる(「自動」は並び順の色)。グラフ・タイマー・記録でその色を使う(`workTypes[].color`) |
| 広い画面 | 幅 900px 以上では、タイマー・記録・予定・設定を真ん中の 860px に寄せる。1200px 以上では、設定を区切りごとに二列に並べる |
| 設定の画面 | 「はじめに(チュートリアルと活用例を一番上に)・表示・記録(アプリ版はほかのアプリと端末の許可も)・メモ・ボード・データ・このアプリ」の区切りに分け、それぞれ見出しの下に箱で囲まずに並べる。一行ごとに左に名前と短い説明、右に操作(入り切りは丸いつまみが左右に動くスイッチ、選ぶものは右寄せ)。テンプレートは名前と行数だけを並べ、押すと開いて書き換えられる(開いたものは描き直しても開いたまま)。広い画面では区切りごとに二列に並べる |
| 太字と文字の色 | 書いている行で文字を選び、操作バーの「B」で太字(パソコンは Ctrl+B でも)。「色」は押すたびに 赤→橙→黄→緑→青→紫→灰→色なし と変わり、長押しで色の一覧(虹色の丸から色の表)を開く。「色」のボタンはいま書く文字の色で、「B」は太字の間は押した見た目で出る。選ばずに押すと、これから書く文字に付く(太字の続きで「B」を押すと、そこから太字をやめる。色の文字の中で「色」を押すと、その色を変える)。太字や色の文字の終わりに続けて書いた文字は、同じ形になる。行の文字には記号を入れず、範囲 `n.f = [{s, e, b:1} | {s, e, c:"赤"|"#rrggbb"}]` で持ち、書き足し・消し・改行・行をつなぐときに範囲もずらす(`setT`・`editFmt`)。書いている間も記号は見えず、文字を透明にした入力欄の上に、同じ位置で色付きの文字を重ねる(太字は字の幅が変わらないよう縁取りで見せる)。以前の形(`**太字**` と `{赤:文字}`)は、メモを開いたときに範囲へ直す。Markdown のコピーでは太字を ** で囲み、色は外す |
| 階層構造 | タブは廃止。記入欄そのものが入れ子のアウトライン(1行=1項目)。改行で次の行、→/Tab で字下げして子に、←/Shift+Tab で戻す(→ ← は操作バーのボタン。パソコンのキーでは Tab/Shift+Tab か Alt+Shift+→/←、Alt+Shift+↑/↓ で行の入れ替え)。行頭の ▾/▸ で畳む。行を長押し(約0.35秒)して持ち上げ、ドラッグでサブツリーごと移動(行頭の ▾/• は長押しなしで動かせる)(行の上部=前へ、中央=子へ、下部=後ろへ。指を右へ約32px寄せるごとに一段深く=子に、左で浅くなる)。「この項目だけ表示」で絞り込み。字下げ付きの文章を貼るとそのまま入れ子になる。行を持ち上げて行のあいだへ落とすときは、動かす前の深さのまま入る(深い子孫の下へ落としても、その子孫の子にはならない)。深さは指を左右に寄せて変える |
| タグ・関連付け・横断検索 | 行の中に `#タグ` と書くとタグ。行どうしを関連付けると双方にリンクが出る。全行を横断して検索 |
| テンプレート(素材・アイテム・設定) | 字下げ付きのひな形を行として挿入。ひな形の【…】は灰色で出し、その行を選ぶと【…】ごと選ばれ、消さずに打てば入れ替わる。行末で改行すると、次の行がひな形の「項目:」でまだ空なら、新しい行を作らずその:の後へ進む。設定で追加・名前変更・削除・中身の編集ができる |
| 作業時間の自動記録 | ページが前面にある間を記録(Page Visibility API)。無操作では止めない |
| 日別・週別・月別の集計 | 対応。作業時間と妨害アプリを並べたグラフと表。日別ではアプリを開いていた時間を1時間ごとの棒グラフで出す |
| マスコット「ミモザ」 | **当面はどちらの版にも出さない**(`SHOW_MIMOZA = false`。戻すときは `NATIVE` にする)。以下は戻したときの動き:**Android アプリ版だけ**。記録画面と初めの案内で吹き出しでしゃべる(画像は `mimoza.png` を埋め込まず、ビルドで assets に写して読む。ブラウザ版には画像もミモザも出ない)。はじめてのときはあいさつ、ふだんはその期間の記録(タイマーの時間、いちばん多い種類、目標、妨害アプリ)に合わせて話し、使い方のひとことも添える。タップで次のセリフ。`Mimoza.say(セリフの配列, 終わったとき)` でどの画面からでもしゃべらせられるので、チュートリアルにも使える |
| 作業の種類と積み上げグラフ | 時間を分ける箱が「作業の種類」。初めは「開発メモ」だけで、作業に数えるアプリを足すとその名前の種類ができる。設定で足す・名前を変える・消す・並べ替える(色は登録順の8色、9つ目からはほかと離れた色を順に作る。点を押して自分で選べる。いくつあっても種類ごとに分かれる)。このアプリを開いていた時間と、各作業アプリの時間は、設定で選んだ種類に入る。タイマーからもどの種類でも選べる。記録画面の主役は種類ごとの積み上げ棒グラフ(日別は1時間ごと、週・月別は1日ごと)と合計。タイマーと重なる時間はタイマーの種類に数え、二重に数えない。記録はタップで種類や時刻を直せる。アプリの使用時間は下の折りたたみへ |
| メモのタグ | 上の「タグ」で、メモそのものにタグを付け外しする(行の中の #タグ とは別)。タグはつながりの帯・ボードのカード・ボードのリストに出て、押すと同じタグのメモの一覧から開ける。検索の「#タグ」でもそのタグのメモが出る。グループ(丸)の設定「このグループ内のメモにタグを追加する」をオンにすると、その丸(中の丸も)に入っているメモに、グループと同じ名前のタグが付く(名前は変えられる。丸から出すと外れる。📁 の印で、自分で付けたタグと区別して出る) |
| 複数のボード | ボードはいくつでも作れ、どれも同じ扱い(すべてのメモを集めるメインのボードはやめた)。いちばん左のボード(初めの名前は「ボード」)は消せず、どのボードにもないメモだけがここへ並ぶ。ボードを消すと、そのボードにだけあったメモはいちばん左へ移る。どのボードでも「＋ 入れる」でほかのメモやグループを入れられる。ゴミ箱へドラッグすると、ほかのボードにもあるメモはこのボードから外すだけ、ここにしかないメモは削除(30日はゴミ箱に残る) |
| ボードのリスト | 「リスト」では、ボードがいくつもあれば、いちばん外はボードの一覧で、ボードはそれぞれ大きなグループとして並ぶ(このときは上のボードの切り替えを隠す。「＋ ボード」もここ)。ボードを押すと、そのボードのいちばん外のグループがタブになって並び、選んだタブのメモが一覧に出る(中のグループは、色の線の付いた見出しの下にまとめる)。グループに入っていないメモは「グループの外」のタブ。「‹ ボード」でボードの一覧へ戻る。メモを押すと開く。「⋯」でボード・グループ・メモのメニュー。右上の「＋ メモ」は、選んでいるタブのグループの中にメモを作ってすぐ書く。「＋ グループ」は新しいグループを作ってそのタブを開く。以前の「タグ」(タグの円が重なる図)は廃止 |
| グループの重なり | 丸(グループ)どうしを重ねると、重なりにあるメモはそのすべてのグループに入る(例:「女性」と「ウサギ族」の重なりにあるキャラクターは両方に入る)。丸がほとんど(9割)別の丸の中にあるときだけ入れ子になり、一部が重なっているだけなら入れ子にしない。左の一覧・リストでは、入っているどのグループの下にも並ぶ。「整列」では、メモを共有して重なっているグループをひとかたまりで動かし、重なりは崩さない。重なっているグループの「中を整列」はしない。グループを丸ごと消すとき、ほかのグループにも入っているメモは残す。グループの丸をドラッグしても、重なりにあるメモはその場に残る |
| 同じメモを複数のボードに | カードの長押し(リストでは ⋯)の「ほかのボードにも置く」で、ボードを続けて選べる(選ぶたびに ✓)。ボードの「＋ 入れる」からも置ける。メインのボードには、すべてのメモが並ぶ |
| メモのリンク | 行の中で `/` を打つと名前の候補が出て、選ぶとリンクになる(日付の 11/1 や A/B では出さない。選ばなければ / はただの文字)。中身は `[[メモの名前]]` で、`[[` から打っても同じ。タップでそのメモへ飛ぶ(名前だけでは飛ばない)。候補の最後の「＋「名前」を新しいメモに」を選ぶと、その名前のメモを作ってリンクにする(書いている所はそのまま)。まだないメモへのリンクを押しても、その場で作れる。つながりの帯に、リンク先(↗)とリンク元(↙)も出る |
| タイマー | ストップウォッチ/ポモドーロ、作業の種類とラベル付き。タイマーの下の「タイマーの設定」で、ポモドーロの集中・休憩の長さ、1日の目標、止め忘れを尋ねるまでの時間(アプリ版は集中ブロックとロック画面の通知も)を変える(以前は設定の画面にあった)。今日のタイマー合計の欄はなくした。記録の「作業」に作業の種類ごとに入り、アプリを開いていた時間や作業アプリとの重なりは二重に数えない。タイマー中に妨害アプリを画面で覆って止めるのは Android アプリ版だけ |
| ドライブで同期 | 設定の「ドライブで同期」で Google アカウントにログインすると、利用者の Google ドライブの、このアプリ専用の隠しフォルダ(appDataFolder)の `worklog-sync.json` を通して、ブラウザ版・アプリ版・別の端末のデータを同じに保つ。開いたとき・書き換えて1分ほどたったとき・閉じるとき・開いている間は3分おきに同期する。その端末で初めての同期は「データの引っ越し」と同じく両方を残して合わせ、以後は文書ごとに新しい方を採る(作業の記録は両方の分を合わせる)。消したメモは、消した時刻より後に書き換えていなければ、ほかの端末でも消える。ブラウザ版は1時間ごとにログインが切れるので、画面の上に細い帯で出る「☁ ログインして同期」で入り直す(上の帯はこのときだけ出る。作業時間を常に出す帯はやめた)。準備は `prototype/worklog-memo-android/DRIVE_SYNC.md`。ブラウザ版は `GOOGLE_WEB_CLIENT_ID` を入れるまで出ない。claude.ai の試作ページでは出ない |
| ブラウザ版 | 同じ `index.html` を、GitHub Pages(https://noneedsgames-ui.github.io/worklog-memo/、公開リポジトリ `noneedsgames-ui/worklog-memo`)と claude.ai の試作ページ(https://claude.ai/artifact/92TaFhMc1gCyY58VBR1CsZ)で開く。claude.ai 以外では同期の説明を出さない。`NATIVE` でないときは、端末のアプリを読む機能(妨害アプリ・作業に数えるアプリの欄、使用状況や集中モードの案内、集中中の注意、アプリの使用時間の折りたたみ、自動バックアップ、端末の許可)を出さず、「このアプリ」を「このページ」と書く。データはアプリ版とは別 |
| 予定 | 日別・週別の一覧、登録・編集・削除、何分前通知 |
| 妨害アプリの使用時間 | Android アプリ版の設定「端末のアプリから選ぶ」で選んだアプリの時間を、端末から自動で読む。名前や分数の手入力はしない。**ブラウザ版からは読めない**ので、以前に記録した時間だけを出す |

## 保存

端末内(localStorage)へ即時に保存し、claude.ai 上で開いた場合は本人専用の領域へも同期する。
初めて同期する端末では同期先の内容を正とし、作業の記録(月ごとの区間・タイマー・使用時間)は両端末の分を合わせる。

## Android アプリ版

`prototype/worklog-memo-android/` は、この `index.html` をそのまま画面に使う Android アプリ(Kotlin)。
ブラウザではできない次の三つを、端末の機能で足している。

| 機能 | しくみ | 必要な許可 |
|---|---|---|
| ほかのアプリの使用時間を読む | 使用状況データ(UsageStatsManager)の前面・背面の出来事から、日ごとの前面時間を数える。設定の「端末のアプリから選ぶ」で選んだアプリは、記録画面で「自動」と出る | 使用状況へのアクセス |
| ホーム画面のウィジェット「作業タイマー」 | 止まっているときは「▶ ストップウォッチ」「▶ タイマー」、計っているときは経過時間(タイマーは集中・休憩の終わる時刻)と「■ 止める」を出す。ボタンはアプリを開いて、そのまま始める・止める(記録は画面側でつける)。タイマーの様子は画面から `Android.timerState` で受け取る。ブラウザ版でも `#start=stopwatch`・`#start=pomodoro`・`#stop` 付きのURLで同じことができる | なし |
| ロック画面の通知 | 止まっているときは「▶ 開始」(ストップウォッチ)、計っているときは大きな経過時間と「■ 止める」を出す。ボタンは通知の本文にあるので、折りたたまれていても押せる。アプリを開かず、ロックを解かずに効く。押した時刻を貯めておき、次に画面が動いたときに記録へ移す。ここから始めても妨害アプリのブロックがかかり(最大5分)、許可が足りず始められないときは通知に警告を出す。タイマー(ポモドーロ)は始められないが、計っている様子と「止める」は出る。設定の「ロック画面に通知を出す」で切れる | 通知(Android 13 以降) |
| 妨害アプリの使用時間を隅に出す | 設定でオンにすると(初期はオフ)、選んだ妨害アプリが前面にある間、そのアプリの今日の合計時間を画面の隅に秒まで出す。タイマーとは関係なく動く。触れない表示で、下のアプリの操作は妨げない。動いている間は通知が一つ出る(`UsageOverlayService.kt`) | 使用状況へのアクセス、他のアプリの上に重ねて表示 |
| 閉じていても届く知らせ | 予定の時刻、ポモドーロの区切り、タイマーの止め忘れを通知で知らせる(`Alarms.kt`)。目覚ましは近い一件だけを端末に預け、鳴ったら預け直す。前面で使っている間は画面の側で知らせる。許可がなくても届くが、数分遅れることがある | 通知、アラームとリマインダー(任意) |
| タイマー中に妨害アプリを使えなくする(試験運用) | タイマーを始めると前景サービスが動き、妨害アプリが前面に出たら画面全体を覆う。**いちどに最大5分**で自動で止まる(タイマー画面からかけ直せる) | 使用状況へのアクセス、他のアプリの上に重ねて表示 |

- ビルドは GitHub Actions(`.github/workflows/worklog-memo-apk.yml`)。Actions の「Run workflow」で手で動かしたときだけ APK を作る。できたものは実行結果の Artifacts から落とす
- 直接入れる APK は試作用の固定のデバッグ鍵(`app/debug.keystore`)で署名し、「開発メモ(試作)」(`.dev`)という別アプリとして入る。前の版の上から入れれば、データは残る
- Google Play の内部テストに出す AAB は、Secrets のアップロード鍵で署名する。手順と Play Console の文案は `prototype/worklog-memo-android/PLAY_RELEASE.md`
- データは端末内に置く(claude.ai への同期も、Android のクラウドバックアップもない。利用者が選んだ保存先へは書き出せる)。ブラウザ版のデータとは別で、設定の「データの引っ越し」で移せる
