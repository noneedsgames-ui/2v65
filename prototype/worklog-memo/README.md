# 作業記録メモ帳(Web試作)

要件定義書「作業時間記録メモ帳アプリ 要件定義書」(2026-11-01)を、スマホのブラウザですぐ試せる形にした試作。
`index.html` 一枚で動く。ネイティブ版(Kotlin / Jetpack Compose / Room)に移る前に、画面の流れと使い心地を確かめるためのもの。

## 要件との対応

| 要件 | Web試作での扱い |
|---|---|
| 起動直後に入力できるメモ | 前回書いていた行(なければ最後の行)から書ける。自動保存 |
| メモとボード | 上の「＋ 新しいメモ」でメモをいくつでも作れる(名前を付けなければ1行目が名前)。「◧ ボード」にはすべてのメモがカードで並び、ドラッグで自由に配置、右下の●を別のカードへ引くと矢印(ラベル・片向き/両向き/線だけ)、空いた所で離すと新しいメモをつないで作る。長押しで色・名前・削除。ドラッグで移動、二本指・ボタンで拡大縮小。「◯ 囲む」で指で描いて囲むと、その形(描いた形の特徴を残しつつ、ある程度ならして整えた形)がファイルになる。線の内側にあるカード・丸が中身で、いくつもの丸に入るときはいちばん内側の丸に属する(入れ子)。カードや丸を線の内側へドラッグすると追加され、丸はそれが収まるようにふくらむ(入れ子なら外側の丸も)。外へ出すと抜ける。名札のドラッグで中の丸・カードごと移動、名札の●で丸同士・丸とカードを矢印でつなぐ、タップで名前・色・形を描き直す・丸を消す(中身はひとつ外側へ)。一定以上縮小すると、カードはタイトルだけになる。丸の名札のメニュー「中を整列」で、中のカードと丸をツリーの順に行と列へそろえ、丸を中身に合う形にする(中の丸から順に)。ファイルごとに色が自動で付き、中のメモはその色で淡く塗られる(設定で切れる)。矢印は自動で色分け(別のファイルのメモ同士=緑、ファイル同士=青で少し太く。設定で色・太さを変えられる)。メモ画面の ☰ で、ファイルとメモの入れ子のツリーを左に出し、長押しで並べ替え・ファイルへの出し入れができる(ボードのカードや丸も、そのファイルの中へ動いて反映され、移した先と元のファイルの中は自動で整列する。設定で切れる)。ボードは上の「図|リスト」で、カードの図と、ツリー形式のリスト(1行目と矢印のつながりも表示、長押しで移動、⋯ で色・名前・削除・整列)を切り替えられる。メモ画面の「つながり」の帯に、そのメモ(と入っているファイル)の矢印が「→ 行き先」「← 来た元」で並び、押せばそのメモへ移る(先がファイルなら中のメモを選ぶ。「‹ 戻る」で一つ前へ)。ファイルの名札を別の丸の上で離すと、大きさに関係なくその中に入って丸がふくらむ。ファイルのメニュー「この中に新しいファイル」、ツリーとリストの「＋ ファイル」で空のファイルも作れる。メモ画面の上の帯はメモの名前と大きな「◧ ボード」ボタンだけで、所属は左のツリーで見る。検索と行の関連付けはメモをまたいで効く |
| 行の形式 | 行ごとに「箇条書き・チェック・番号付き・タイムライン・見出し・補足・コード」を選べ、一つのメモの中で混ぜられる(操作バーの「形式」)。Markdown の記号(`[] ` `[x] ` `1. ` `@時 ` `# ` `> ` ```` ``` ````)を行の頭で打っても変わる(全角も可)。印は箇条書きの「•」と同じ場所に置き、タイムラインは続く行どうしを一本の線でつなぐ。改行で同じ形式が続き、空のまま改行するとふつうの行に戻る。Markdown や ☐/☑ の文章を貼ると形式として読み込む |
| コピー・選択・削除 | 上の「コピー」でメモ全体を、記号つきの文章か Markdown にしてコピー。「選択」で行を複数選び、まとめてコピー・形式の変更・削除。操作バーの「削除」で1行削除。削除の直後は「元に戻す」が出る |
| 階層構造 | タブは廃止。記入欄そのものが入れ子のアウトライン(1行=1項目)。改行で次の行、→/Tab で字下げして子に、←/Shift+Tab で戻す。行頭の ▾/▸ で畳む。行を長押し(約0.35秒)して持ち上げ、ドラッグでサブツリーごと移動(行頭の ▾/• は長押しなしで動かせる)(行の上部=前へ、中央=子へ、下部=後ろへ。指を右へ約32px寄せるごとに一段深く=子に、左で浅くなる)。「この項目だけ表示」で絞り込み。字下げ付きの文章を貼るとそのまま入れ子になる |
| タグ・関連付け・横断検索 | 行の中に `#タグ` と書くとタグ。行どうしを関連付けると双方にリンクが出る。全行を横断して検索 |
| テンプレート(素材・アイテム・設定) | 字下げ付きのひな形を行として挿入。ひな形の【…】は灰色で出し、その行を選ぶと【…】ごと選ばれ、消さずに打てば入れ替わる。設定で追加・名前変更・削除・中身の編集ができる |
| 作業時間の自動記録 | ページが前面にある間を記録(Page Visibility API)。無操作では止めない |
| 日別・週別・月別の集計 | 対応。作業時間と妨害アプリを並べたグラフと表。日別ではアプリを開いていた時間を1時間ごとの棒グラフで出す |
| マスコット「ミモザ」 | 記録画面で吹き出しでしゃべる(画像は `mimoza.png`)。はじめてのときはあいさつ、ふだんはその期間の記録(タイマーの時間、いちばん多い種類、目標、妨害アプリ)に合わせて話し、使い方のひとことも添える。タップで次のセリフ。`Mimoza.say(セリフの配列, 終わったとき)` でどの画面からでもしゃべらせられるので、チュートリアルにも使える |
| 作業の種類と積み上げグラフ | 設定で作業の種類を登録し(色は登録順に固定の8色、9つ目からは「その他」)、タイマーで種類を選んで計る。記録画面の主役は「作業時間の内訳」の積み上げ棒グラフ(項目の間にすき間を空けずに積む。日別は1時間ごと、週・月別は1日ごと)と内訳ごとの合計。内訳は「計画メモ(このアプリを開いていた時間のうちタイマーと重ならない分)」「作業の種類(タイマー)」「作業アプリ(週・月別と合計のみ)」で、重なりは二重に数えない。上の「作業」とミモザもこの合計。記録はタップで種類の付け替え・削除。アプリの使用時間は下の折りたたみへ |
| メモのタグ | 上の「タグ」で、メモそのものにタグを付け外しする(行の中の #タグ とは別)。タグはつながりの帯・ボードのカード・ボードのリストに出て、押すと同じタグのメモの一覧から開ける。検索の「#タグ」でもそのタグのメモが出る。ファイル(丸)の設定「このファイル内のメモにタグを追加する」をオンにすると、その丸(中の丸も)に入っているメモに、ファイルと同じ名前のタグが付く(名前は変えられる。丸から出すと外れる。📁 の印で、自分で付けたタグと区別して出る) |
| 複数のボード | ボード画面の上の帯で、ボードを切り替え・作成する。「◧ メイン」にはすべてのメモが自動で並ぶ。新しいボードには「＋ 入れる」で、メモを選んで置いたり、ほかのボードのファイル(丸)を中のメモ・中の丸・その間の矢印ごと写したりできる。同じメモを複数のボードに置け、丸・矢印・位置・表示の倍率はボードごとに別々。カードのメニューで「ほかのボードにも置く」「このボードから外す(メモは残す)」。いまのボードの名前の ▾ で、名前・並び順・削除(メモは消えない) |
| タグの表示(ベン図) | ボードの「図|リスト|タグ」の「タグ」で、いまのボードのメモをタグで分けて表示する。選んだタグ(3つまで、初めは多い順)が重なる円になり、メモは当てはまる重なりの中に置かれる(多いときは「ほか N件」から一覧)。どの円にも入らないメモは下に並ぶ。タップで開く |
| メモのリンク | 行の中で `/` を打つと名前の候補が出て、選ぶとリンクになる(日付の 11/1 や A/B では出さない。選ばなければ / はただの文字)。中身は `[[メモの名前]]` で、`[[` から打っても同じ。タップでそのメモへ飛ぶ(名前だけでは飛ばない)。まだないメモはその場で作れる。つながりの帯に、リンク先(↗)とリンク元(↙)も出る |
| タイマー | ストップウォッチ/ポモドーロ、作業の種類とラベル付き。作業時間には加算しない。集中中にこのページを1分以上離れると、戻ったときに何を使っていたか聞き、選んだアプリ(作業アプリ/妨害アプリ)の時間として記録する。**ほかのアプリを使えなくすることはWebではできない**ため、Android の集中モードの手順を案内する(ネイティブ版では画面で覆って止める) |
| 予定 | 日別・週別の一覧、登録・編集・削除、何分前通知 |
| 妨害アプリの使用時間 | **自動取得できない**ため、記録画面で分数を手入力するか、タイマー中の問いかけで記録する |
| 作業に数えるアプリ | 設定で選んだアプリ(お絵描き・ドット絵など)の使用時間を作業時間に足す。入力方法は妨害アプリと同じ |
| 予定の通知 | **ページを開いている間だけ**音と表示で知らせる |
| データの引っ越し | 設定の「データの引っ越し」で、メモ・ボード・予定・設定・作業の記録を JSON ファイル(または文章のコピー)に書き出し、ブラウザ版とアプリ版のあいだなどへ移せる。読み込みは今のデータに合わせる:記録は両方の分を足し、同じメモの中身が違えば新しい方を残して古い方を「(別の版)」として残す。同じ名前の作業の種類・アプリは一つにまとめる。消したメモは、読み込んだファイルに入っていれば戻る |

## 保存

端末内(localStorage)へ即時に保存し、claude.ai 上で開いた場合は本人専用の領域へも同期する。
初めて同期する端末では同期先の内容を正とし、作業の記録(月ごとの区間・タイマー・使用時間)は両端末の分を合わせる。

## Android アプリ版

`prototype/worklog-memo-android/` は、この `index.html` をそのまま画面に使う Android アプリ(Kotlin)。
ブラウザではできない次の三つを、端末の機能で足している。

| 機能 | しくみ | 必要な許可 |
|---|---|---|
| ほかのアプリの使用時間を読む | 使用状況データ(UsageStatsManager)の前面・背面の出来事から、日ごとの前面時間を数える。設定の「端末のアプリから選ぶ」で選んだアプリは、記録画面で「自動」と出る | 使用状況へのアクセス |
| ホーム画面のウィジェット「作業タイマー」 | 止まっているときは「▶ ストップウォッチ」「▶ タイマー」、計っているときは経過時間(タイマーは集中・休憩の終わる時刻)と「■ 止める」を出す。ボタンはアプリを開いて、そのまま始める・止める(記録は画面側でつける)。タイマーの様子は画面から `Android.timerState` で受け取る。ブラウザ版でも `#start=stopwatch`・`#start=pomodoro`・`#stop` 付きのURLで同じことができる | なし |
| タイマー中に妨害アプリを使えなくする(試験運用) | タイマーを始めると前景サービスが動き、妨害アプリが前面に出たら画面全体を覆う。**いちどに最大5分**で自動で止まる(タイマー画面からかけ直せる) | 使用状況へのアクセス、他のアプリの上に重ねて表示 |

- ビルドは GitHub Actions(`.github/workflows/worklog-memo-apk.yml`)。HTML 版を磨いている間は、Actions の「Run workflow」で手で動かしたときだけ APK を作り、Releases に置く
- 直接入れる APK は試作用の固定のデバッグ鍵(`app/debug.keystore`)で署名し、「作業記録メモ帳(試作)」(`.dev`)という別アプリとして入る。前の版の上から入れれば、データは残る
- Google Play の内部テストに出す AAB は、Secrets のアップロード鍵で署名する。手順と Play Console の文案は `prototype/worklog-memo-android/PLAY_RELEASE.md`
- データは端末内のみ(claude.ai への同期はない)。ブラウザ版のデータとは別で、設定の「データの引っ越し」で移せる
