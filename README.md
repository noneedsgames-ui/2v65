# 開発メモ

メモ・ボード・作業時間の記録・予定を一つにまとめたアプリ。

| 場所 | 中身 |
|---|---|
| `prototype/worklog-memo/` | アプリの本体(`index.html`)と機能の一覧(`README.md`) |
| `prototype/worklog-memo-android/` | Android アプリ(WebView で `index.html` を出す) |
| `.github/workflows/worklog-memo-apk.yml` | APK・AAB を作る GitHub Actions |

ブラウザ版は https://noneedsgames-ui.github.io/worklog-memo/ で配っている。
